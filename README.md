# Nikon B2C Review — Nikon Singapore × VHG

Interactive presentation for the Nikon Singapore visit (October 2026): B2C activation results on the Nikon Vietnam Shopee & TikTok Shop stores, Shop Mall progress, Q4 proposals and support asks.

- `index.html` — the whole app (HTML/CSS/JS, native SVG charts, no build step)
- `assets/` — listing images, campaign banners, vouchers, Seller Centre screenshots (WebP)
- `fonts/` — Archivo, Instrument Sans, IBM Plex Mono (self-hosted)

## Run locally
Open `index.html` in a browser, or serve the folder: `python3 -m http.server` → http://localhost:8000

## Present
Press **P** (or the Present button) for slide snapping, arrow keys / Page Up-Down to move, **F** for full screen.

Data: Shopee Seller Centre exports — orders Jan 2024 – Sep 2026, Flash Sale to 15 Oct 2026, Ads Jun–Sep 2026. Internal and confidential; keep this repository private.
